# Manuscripter Technology

**الحالة:** ✅ قيد الاستخدام

**الهدف:** عرض صور المخطوطات مع أدوات تكبير وتحريك ومقارنة نسخ.

**المكونات الرئيسية:**
- `ManuscriptViewer.vue`: العارض الرئيسي
- `Components/`: مكونات فرعية (مخطط للمستقبل)
  - ImageCanvas.vue
  - ZoomControls.vue
  - PanControls.vue
  - VersionTabs.vue

**الاستخدام:**
```javascript
import ManuscriptViewer from '@/Technologies/Manuscripter/ManuscriptViewer.vue'
```

**الميزات:**
- عرض صور المخطوطات
- Zoom In/Out
- Pan (التحريك)
- مقارنة نسخ متعددة
- التبديل بين النسخ
