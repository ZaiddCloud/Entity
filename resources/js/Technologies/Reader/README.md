# Reader Technology

**الحالة:** 🚧 تحت التطوير المستقبلي

**الهدف:** توفير واجهة قراءة متقدمة للزوار (غير المحررين) لقراءة الكتب والمخطوطات.

**المخطط:**

## Components/
- `BookReader.vue`: المكون الرئيسي
- `PageView.vue`: عرض الصفحات
- `TableOfContents.vue`: جدول المحتويات
- `ReadingControls.vue`: أدوات القراءة (حجم الخط، السمة، إلخ)

## Themes/
- `LightTheme.js`: السمة الفاتحة
- `DarkTheme.js`: السمة الداكنة

**الاستخدام المخطط:**
```javascript
import BookReader from '@/Technologies/Reader/BookReader.vue'
```

**الميزات المخططة:**
- عرض نظيف للقراءة
- جدول محتويات تفاعلي
- تغيير حجم الخط
- سمات فاتحة/داكنة
- وضع ملء الشاشة
- حفظ موضع القراءة
- التنقل بين الصفحات
- البحث في النص
